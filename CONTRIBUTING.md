# Contributing

Read PRODUCT.md, DESIGN.md and AGENTS.md before changing the interface or processing pipeline. Keep engine claims tied to actual runtime checks, preserve originals and clearly distinguish conventional filters from AI restoration.

Python 3.12+, Node 24, FFmpeg and Docker are used for development. The README lists the verification commands. Use generated test clips; do not commit library media, credentials, model checkpoints or local evidence.

For design changes, install [Taste](https://tasteskill.dev) and [Impeccable](https://impeccable.style), preserve the neutral palette and accessible controls, and inspect desktop/mobile light/dark workflows. Record evidence and remaining device acceptance in working.md.

Keep changes focused. Use a pull request for external contributions and include the behavior changed, verification performed and hardware actually tested. Maintainer sessions finish with reviewed work merged into main and obsolete branches removed. Do not add AI co-author tags. Maintainer commits use thekozugroup@gmail.com; external contributors retain their own identity.

Contributions to Popcorn SR are under AGPL-3.0-or-later. Third-party SDKs, models and reference projects retain their own terms. Do not vendor proprietary engine binaries or code without redistribution rights.
