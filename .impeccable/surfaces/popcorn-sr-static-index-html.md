# Popcorn SR workspace

Mode: Operate. Code-led implementation. Target: the authenticated web workspace.

## Direction contract

THESIS: Make remote video processing feel like a simple local library task. Keep the next action clear and put technical setup in short guidance.

OWN-WORLD: Neutral Tailwind zinc surfaces, blue-500 actions with accessible dark text, restrained system sans, flat sections, thin dividers and familiar 44px controls. Honor light/dark system preference and reduced motion.

STORY: Choose a library video, connect verified processing, make a short preview, then continue the full copy using saved settings. Every original stays separate and protected.

FIRST VIEWPORT: A consistent sidebar, a clear choose-video action, a real library-to-worker-to-output diagram and three ordered onboarding steps. No fabricated activity or hardware readiness.

FORM: Inline recipe and pairing sections with a durable queue. Completed previews offer a direct full-video continuation. seed: none (unavailable).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Verification

Chromium captures at 390, 768 and 1440; light/dark and reduced-motion coverage. Real CPU preview-to-full processing, authenticated downloads, accessibility and overflow checks. GPU processing remains a separate physical acceptance gate.
