Finished copies

Choose a subfolder when creating a job. Originals are never replaced.

Temporary storage

Each worker owns its scratch drive. Video downloads, intermediates and uploads use that drive; small pairing credentials use its state folder. Check the host's swap and Docker storage configuration to keep those writes off the built-in drive too.

Network

Direct Ethernet or a shared router/switch works. A plain USB-C cable does not establish a network between ordinary host ports. Wi-Fi works, with transfer speed and reliability depending on your network.

Protected sources

This release rejects HDR and high-bit-depth input to prevent loss of color or detail. Keep your original and use a verified HDR pipeline for those files.

Access

Keep the manager on your trusted network. Use HTTPS through a reverse proxy or VPN for remote access.
